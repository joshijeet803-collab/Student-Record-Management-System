# Student Record Management System

A web-based Student Record Management System developed using Core PHP, Laravel, and MySQL.

## Project Versions

### 1. Core PHP
- User Registration and Login
- Admin Dashboard
- Student Management (Add, View, Edit, Delete)
- Search and CSV Export
- Contact Messages and Replies
- MySQL Database Integration

### 2. Laravel
- User and Admin Authentication
- Student Management
- Dashboard
- Contact Messages and Replies
- MySQL Database Integration
- Responsive User Interface

## Technologies Used

- PHP
- Laravel
- MySQL
- HTML5
- CSS3
- Bootstrap
- JavaScript

## Installation

### Core PHP
1. Copy the Core-PHP folder into XAMPP htdocs.
2. Start Apache and MySQL.
3. Import the database.sql file using phpMyAdmin.
4. Configure the database connection in config.php.
5. Open the project in your browser.

### Laravel
1. Open the Laravel folder in VS Code.
2. Run composer install.
3. Configure the .env file.
4. Set up the MySQL database.
5. Run php artisan serve.
